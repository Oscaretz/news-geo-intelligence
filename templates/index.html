Technical Documentation

Arquitectura y especificaciones técnicas del ecosistema.

account_tree Topología memory Pipeline ETL database Modelo de Datos smart_toy Modelos (LLMs) chat AI Chatbot map Catálogos cloud_upload Despliegue

1. Topología de la Arquitectura

La solución se apoya en un ecosistema de microservicios Dockerizados que orquestan el ciclo de vida del dato analítico.

imageDiagrama / Captura
Flask (Web): Proporciona endpoints RESTful asíncronos y sirve la interfaz frontend construida con Tailwind CSS y Vanilla JS.
PostgreSQL (OLAP Storage): Motor persistente central, configurado con esquemas transaccionales para raw data y tablas relacionales orientadas a análisis.
Dagster Webserver (UI): Expone el panel de control gráfico de Dagster, permitiendo trazar linaje de datos y monitorear el estado de los runs en tiempo real.
Dagster Daemon: Coordinador de ejecución en background que maneja la persistencia de colas, retries y schedulers.

2. Pipeline ETL y Orquestación (Dagster)

La lógica de negocio asíncrona está encapsulada en Software-Defined Assets (SDAs) de Dagster (etl/definitions.py). Este orquestador coordina las recolecciones de información y los motores de inferencia masiva.

imageDiagrama / Captura

El flujo inicia extrayendo metadatos no procesados, los cuales se agrupan y paralelizan hacia los nodos computacionales (LLM). Si ocurre una falla irrecuperable en un lote, el sistema descarta los registros en una Dead Letter Queue (DLQ) local para inspección manual, permitiendo que el pipeline principal continúe sin afectar la integridad del DAG.

3. Modelo de Datos

El almacén implementa un esquema en estrella (OLAP Star Schema) diseñado para maximizar el rendimiento (throughput) de las lecturas analíticas en el frontend.

imageDiagrama / Captura
fact_news_metrics: Tabla de hechos conteniendo la granularidad atómica por artículo (conteo de palabras, sentimiento).
Tablas de Dimensión: dim_date, dim_source, dim_entities.

La ingesta utiliza lógica idempotente mediante operaciones UPSERT (ON CONFLICT DO UPDATE o DO NOTHING), garantizando que las reejecuciones del ETL no generen duplicados ni violaciones de primary keys.

4. Integración de Modelos (LLMs)

La inferencia semántica se fundamenta en un flujo híbrido tolerante a fallos a través de las SDKs de Groq y Gemini (Flash).

imageDiagrama / Captura

El sistema emplea Prompt Engineering estricto para forzar la salida de JSON validable. Los esquemas Pydantic dictan el contrato de datos esperado. Instrucciones específicas fuerzan al modelo a limpiar variaciones lingüísticas y jerga (como "Edomex") hacia vectores estandarizados ("Estado de México"), garantizando uniones (joins) relacionales precisas en la fase de mapeo geográfico.

5. Asistente Conversacional (RAG)

El motor integra un asistente analítico avanzado que permite consultar el modelo relacional subyacente.

imageDiagrama / Captura
Streaming API: Implementado vía Server-Sent Events (SSE) nativos en Flask para el renderizado asíncrono y progresivo de las respuestas en el frontend, evitando timeouts HTTP.
Inyección de Contexto: El LLM recibe dinámicamente un volcado serializado de métricas y acceso a las ejecuciones históricas para responder utilizando la técnica Retrieval-Augmented Generation.

6. Capa de Catálogos (GeoJSON & i18n)

El sistema expone configuraciones modulares permitiendo escalar la plataforma horizontalmente sin modificar el código base.

imageDiagrama / Captura
Caché en Memoria (Geometrías): Las topologías territoriales se precargan (geojson_cache.py) desde map_config.json y archivos vectoriales estáticos, reduciendo dramáticamente el consumo de I/O en la renderización de Leaflet.
Internacionalización (i18n): El frontend abstrae un diccionario inyectado que permite conmutar claves data-i18n mediante iteradores JavaScript en el cliente.

7. Despliegue y Repositorio

El despliegue está contenerizado. Los comandos operativos principales son los siguientes:

# 1. Clonar el repositorio
git clone <repository_url>
cd google_news_scraping

# 2. Configurar variables de entorno
cp .env.template .env
# Editar .env (DATABASE_URL y API Keys: GROQ, GEMINI)

# 3. Construir y levantar servicios
docker-compose up -d --build

Manual de Usuario

Guía de operación de la plataforma AI News Explorer.

menu_book Descripción search Búsqueda analytics Dashboard public Mapa Interactivo forum Asistente AI history Historial settings Configuración

1. Descripción General

AI News Explorer es una plataforma de análisis de información y monitoreo de noticias. Te permite buscar cualquier tema de interés, recolectar las noticias más recientes al respecto, y obtener un análisis visual e inteligente del tono (positivo o negativo), la distribución geográfica y los conceptos clave abordados en los artículos.

imageDiagrama / Captura

2. Panel de Búsqueda y Filtros

El primer paso es utilizar la barra principal superior. Escribe un término (ejemplo: "Elecciones" o "Inteligencia Artificial") y presiona el ícono de filtro para configurar parámetros avanzados:

imageDiagrama / Captura
Palabras Secundarias: Obliga a que los resultados incluyan términos específicos.
Excluir Palabras: Útil para limpiar el ruido (ej. si buscas "Apple", excluir "fruta").
Rango de Fechas: Delimita la antigüedad de la noticia.
Filtro de Dominio: Restringe fuentes (ej. .mx, bbc.com).
Cantidad y País: Fija el límite máximo de resultados a extraer y la región que guiará el mapa.
info

Nota de Espera

La recolección es un proceso asíncrono profundo. Las búsquedas de gran cantidad de noticias (ej. 50 resultados) requerirán un momento para procesar, leer e interpretar cada texto.

3. Dashboard Analítico y KPIs

Una vez finalizada la extracción, la pestaña "Análisis y Mapas" muestra el resumen inteligente de los datos.

imageDiagrama / Captura
Indicadores Clave (KPIs): Tarjetas superiores que muestran el total de artículos evaluados, cuántos lograron mapearse a una zona y el "Tono Promedio" (un indicador que varía hacia el verde si las noticias son positivas, o hacia el rojo si son negativas).
Gráfico de Fuentes (Pastel): Visualiza qué periódicos o portales generaron la mayor cantidad de artículos sobre el tema.
Evolución en el Tiempo: Gráfica de línea mostrando los picos de publicación de las noticias recolectadas.

4. Mapa Interactivo y Geolocalización

La herramienta de mapa colorea los estados de un país (como México o Estados Unidos) según la cantidad de noticias que hacen mención a esa región específica.

imageDiagrama / Captura
Filtrado con clic: Al hacer clic en un estado oscuro (con mucha actividad), la tabla de noticias a la derecha se filtrará instantáneamente para mostrar únicamente lo que ocurrió en ese lugar.
Botón "Extraer Ubicaciones": Es el paso clave de la plataforma. Una vez que tengas las noticias base, presiona este botón superior para que la Inteligencia Artificial lea el contenido, detecte ciudades o estados mencionados y encienda el mapa de calor.

5. Asistente Inteligente (Chatbot)

El panel colapsable del lado derecho contiene un asistente conversacional capaz de leer toda tu búsqueda actual.

imageDiagrama / Captura

Puedes pedirle en lenguaje natural cosas como: "Resume las noticias negativas relacionadas con la Ciudad de México" o "Crea una lista de las 5 personas más mencionadas en los reportajes". El chatbot entiende contexto completo y puede devolver listados o tablas ordenadas para tus propios informes.

6. Historial y Monitoreo de Trabajos

La plataforma no olvida tus búsquedas previas.

imageDiagrama / Captura
Pestaña de Historial: Actúa como un archivo. Si ejecutaste una búsqueda grande ayer, puedes venir a esta pestaña y darle clic para recargar instantáneamente todos los gráficos y el mapa sin tener que volver a esperar el proceso de extracción.
Pestaña de Trabajos (Jobs): Muestra un registro en tiempo real de todo lo que el sistema está procesando por detrás. Verás cuando una tarea está "Ejecutando", y cuando ha sido "Exitosa".

7. Opciones de Configuración y Exportación

imageDiagrama / Captura
Exportar Datos: Arriba a la derecha de la plataforma encontrarás el botón de exportación. Este compilará todas las métricas, entidades detectadas y links a los artículos en un archivo de Excel para descarga, facilitando tu trabajo en herramientas como PowerBI.
Selector de Idioma: El ícono de engranaje (Settings) expone una palanca rápida para traducir absolutamente todos los menús, etiquetas y botones de la plataforma entre Español e Inglés al instante.
